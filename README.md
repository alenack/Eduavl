# EduAVL – Student Records on an AVL Tree (C backend)

## Run locally
- Windows: `run.bat`  (needs MinGW gcc)
- Linux/Mac/WSL: `make && ./server` then open http://localhost:8080

## Deploy permanently (Render, free)
1. Push this folder to a GitHub repo.
2. render.com -> New -> Web Service -> pick the repo (it detects the Dockerfile).
3. Plan: Free. Deploy. You get https://<name>.onrender.com
